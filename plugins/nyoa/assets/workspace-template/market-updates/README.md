# Market Updates

Monthly market commentary. One file per month, named `YYYY-MM.md`.

Each file contains the three-format package generated by `/nyoa-market-update`:
- Blog post (400-500 words, SEO-shaped)
- Instagram caption (≤ 200 words + hashtags)
- Email newsletter (300-400 words)

Plus a header block listing the inputs (stats + source) so the data is auditable later.

## Why one folder

Keeping every month in one place lets `/nyoa-market-update` reference last month's thesis when drafting the next month's piece, building narrative continuity. The agent doesn't have to copy/paste prior takes — the skill reads them.

## Convention

- File name: `YYYY-MM.md` (e.g., `2026-04.md` for the April 2026 piece).
- Don't overwrite. If the skill is re-run with corrected data, the prior version is moved to `YYYY-MM.bak.md` before the new one is written.
- Append-only safe to edit by hand. Just keep the section headers (`## Blog post`, `## Instagram`, `## Email`) so the next run can parse them.
