# Closing Checklist

Generic — adapt by state and transaction type.

## Pre-close
- [ ] Final walk-through scheduled
- [ ] Repairs verified (per inspection response)
- [ ] Appraisal cleared
- [ ] Loan clear-to-close
- [ ] Closing disclosure reviewed
- [ ] Wire instructions verified (call lender to confirm)
- [ ] Utilities transfer scheduled
- [ ] Insurance bound (buyer)
- [ ] Home warranty (if negotiated)

## Day of close
- [ ] ID + funds confirmed
- [ ] Keys, garage remotes, manuals collected (seller)
- [ ] Recording confirmation

## Post-close
- [ ] Send closing gift
- [ ] Add to past-client cadence (templates/follow-up-cadence.md)
- [ ] Request review (run `/nyoa-testimonial-engine`)
- [ ] Update pipeline.md → Closed
