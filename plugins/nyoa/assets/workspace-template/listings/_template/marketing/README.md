# {{address}} — Marketing

Per-event marketing artifacts for this listing. One file per event.

## Files

- `open-house-YYYY-MM-DD.md` — full open-house promotion package written by `/nyoa-open-house`. One per open house weekend.
- `3d-tour.md` — canonical record for the listing's 3D Gaussian Splat tour (URL, capture date, hosting platform, embed snippets, refresh history). Managed by `/nyoa-3d-tour`. One file per listing — refreshed on price drop, re-stage, or relist.
- `vendor-brief-3d-tour.md` — written by `/nyoa-3d-tour vendor`. The outbound email brief sent to a freelance scanner.
- `3d-tour-promo-YYYY-MM-DD.md` — written by `/nyoa-3d-tour promote`. Social posts + buyer email + open-house add-on for a single tour-promotion cycle. One per promo wave.
- (Other marketing event files land here as future skills are added — carousel scripts, photoshoot briefs, just-sold packages.)

## Convention

- File name encodes the event date, not the create date.
- Don't overwrite. Each event gets its own file so historical packages stay searchable for the next price-drop refresh or relist.
