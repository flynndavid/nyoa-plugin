# Review Request SMS

≤320 chars. Send 5–7 days after email if no response.

```
Hey [first name] — I sent a note last week about leaving a quick review. Totally optional, but if you have 2 mins it helps a lot: [short link]. Thanks again for trusting me with [brief reference]. — [Agent first name]
```

**Rules:**
- Casual, not pushy
- Reference the email so it doesn't feel random
- Keep the link short (agent should use a short URL)
- No "Hi [name]," opener (too template-y for SMS)
- One send only — if they don't respond to the SMS, let it go
- Sign with first name or initials
