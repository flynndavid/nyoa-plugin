# Open House — Facebook Event Description

**Required:** address, date, time window, list price, 3-5 standout features, parking notes, agent attribution.
**Length:** 200–300 words.

---

## Structure

1. **One-line headline** — repeat the date + window + address so it survives in a notification preview.
2. **What this listing actually is** — 2-3 sentences. Beds/baths/sqft, lot, one signature feature, list price.
3. **Bulleted feature list** — 3-5 bullets. Concrete only.
4. **Logistics paragraph** — parking, pets, kids welcome (without saying "great for families"), refreshments if any.
5. **Agent attribution footer** — name, brokerage, license number. Required.
6. **Compliance footer** — verbatim per SKILL.md.

## Compliance check

- "Primary bedroom" not "master".
- No "family-friendly", "great schools", "safe neighborhood", "diverse" etc.
- Renovation claims must be confirmed.
- License + brokerage required.
- No "won't last" or other pressure clichés.
