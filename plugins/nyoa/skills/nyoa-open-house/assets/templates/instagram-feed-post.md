# Open House — Instagram Feed Post

**Required:** address, date, time window, list price, 3 standout features.
**Length:** ≤ 180 words, including hashtags.

---

## Structure

1. **Hook (line 1)** — the why-now. What about this property + this weekend matters. Not "open house this Saturday".
2. **Body (2–4 short lines)** — three concrete features. Plain language. No clichés.
3. **Logistics line** — date, window, address.
4. **CTA** — a low-friction next step. Comment, DM, walk in. Pick one.
5. **Hashtags** — 12–15. Mix of neighborhood, market, niche. Skip the broad ones.

## Skeleton

```
{{why_now_hook}}

{{feature_1_one_sentence}}
{{feature_2_one_sentence}}
{{feature_3_one_sentence}}

{{date_short}}, {{time_window}}. {{address_with_neighborhood}}.

{{cta_line}}

{{hashtags}}
```

## Compliance check

- No "perfect for families" / demographic targeting.
- No "stunning" / "must see" / "won't last".
- No school quality claims. District names neutrally OK.
- "Primary bedroom" not "master".
- If a feature is a renovation claim ("updated kitchen"), it must already be confirmed in `property.md` or the agent's brief.
