# New-Listing Email Blast Template

**Channel:** Email to the agent's buyer list / sphere.
**Length:** Subject ≤55 chars. Body 120–220 words.

## Structure

### Subject line
- Concrete, specific, one feature. Personal-sounding.
- **Good:** "New on Maple St — 1924 craftsman, six-burner Wolf range"
- **Good:** "Sylvan Park: 3/2 with a creek lot just hit MLS"
- **Bad:** "🔥 JUST LISTED! Stunning home you NEED to see!"
- **Bad:** "New listing alert"
- 0 emojis. 0 all-caps. 0 "JUST LISTED".

### Preheader (optional, ≤90 chars)
The second sentence of the email essentially. Adds a complementary detail to the subject.

### Body

#### Opening (2–3 sentences)
Address. Hook (same hook as MLS remarks). One sentence of context for *this list* — why this list is hearing about it (e.g., "I know a lot of you have been watching East Nashville for the right craftsman — this is one.").

#### Property block
- **Address** + neighborhood
- **Price** · **Beds / baths / sqft**
- **3–5 features** as a clean list (the same anchors from MLS / IG)

#### Action block
- Open house time(s)
- "Reply to this email to set up a private showing this week" (or scheduling link if the agent has one)
- Link to the listing page (Zillow / agent site / MLS)

#### Sign-off
First name. No "Best regards" template-speak. Match agent voice file if available.

## Hard rules

- 0 Fair Housing red flags
- 0 unsourced structural claims
- 0 clichés
- "Primary bedroom" not "master bedroom"
- Subject ≤55 chars
- Body ≤220 words
