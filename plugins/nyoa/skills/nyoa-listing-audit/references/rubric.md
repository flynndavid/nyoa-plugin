# Listing Audit Rubric

Score each dimension 1–5. Total out of 40. Letter grade:
- 36–40 = A
- 32–35 = B
- 28–31 = C
- 24–27 = D
- ≤23 = F

---

## 1. Hook strength

The first sentence has one job: stop a buyer who is scrolling Zillow at 11pm. If they would not pause on this sentence, the listing has no hook.

- **5** — Specific, concrete, image-forward, names something only this house has.
- **4** — Specific and concrete but generic to category (e.g., "renovated craftsman").
- **3** — Adequate. Names a real feature but no scene.
- **2** — Cliché-driven ("stunning", "nestled", "boasts").
- **1** — Generic + cliché-stacked + no specifics.

## 2. Lifestyle clarity

Can a buyer picture their actual life there — Saturday morning, weeknight dinner, working from home?

- **5** — Two or more concrete scenes a buyer can step into.
- **3** — One scene or implied lifestyle.
- **1** — Pure feature list, no lifestyle.

## 3. Specificity

Concrete features, dimensions, finishes, materials beats vague adjectives.

- **5** — Named finishes (quartz, white oak, soapstone), real dimensions ("third bedroom fits a queen + full desk"), real materials.
- **3** — Some specifics, mostly adjectives.
- **1** — All adjectives, no nouns. "Beautifully updated throughout."

## 4. Photo–copy alignment

The copy and the photos tell the same story.

- **5** — Every claim in the copy is visible in at least one photo.
- **3** — One or two minor mismatches.
- **1** — Major contradictions ("move-in ready" + photos of construction; "open concept" + photos of clearly walled rooms).

## 5. Buyer-targeting

The listing is written for a specific buyer profile. Generic = bad.

Buyer profiles:
- First-time buyer
- Move-up buyer
- Downsizer / empty nester
- Investor / landlord
- Luxury buyer
- Land / fixer / developer

Score:
- **5** — Clear profile, language and selected features match.
- **3** — Implicit profile, mostly aligned.
- **1** — Generic. Could be any house, any buyer.

## 6. Compliance & risk

Fair Housing language, structural claim integrity, school-district risk.

**Red-flag phrases** (these tank the score regardless of other dimensions):

- "Great for families" / "perfect for kids" / "family neighborhood" — familial status
- "Master bedroom" — many MLS systems now require "primary bedroom"
- "Walk to [house of worship]" — religion
- "Quiet [ethnic/cultural] neighborhood" — national origin / race
- "Bachelor pad" / "starter home for newlyweds" — sex / familial status
- "Handyman special" / "needs TLC" — usually fine but watch for ADA implications
- "Exclusive" / "private community" — sometimes flagged

**Structural-claim risk:**
- "Fully renovated" / "completely updated" / "new everything" — only if verifiable in the source
- "New roof / HVAC / electrical" — only if listing or seller's disclosure backs it up

**Score:**
- **5** — Clean. No flagged language. All structural claims sourced.
- **3** — One minor borderline phrase.
- **1** — Multiple Fair Housing red flags or unsourced structural claims.

## 7. Call to action

What does the buyer do next? Is the path obvious and frictionless?

- **5** — Clear next step (open house time, scheduling link, agent contact, deadline).
- **3** — Implicit ("contact for showing").
- **1** — None. Listing just ends.

## 8. Differentiation

Does this sound like a specific home, or like every other listing in the MLS?

- **5** — Unmistakably this house. Could not be swapped for another listing in the same neighborhood.
- **3** — Some unique notes, mostly interchangeable.
- **1** — Could be ctrl-C / ctrl-V'd onto any house in the zip.
