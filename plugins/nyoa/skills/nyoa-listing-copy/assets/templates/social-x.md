# X (Twitter) Post Template

**Length:** ≤280 chars. Single post (no thread by default — agent can ask for one).

## Structure

One post, three moves:

1. **Line 1** — The hook. Concrete detail. No emojis, no all-caps, no agent jargon.
2. **Line 2** — One number that anchors value (price, beds/baths/sqft, year built, lot size — pick the most surprising).
3. **Line 3** — Action: open house time OR a link.

## Hard rules

- ≤280 characters total
- ≤1 emoji (preference: 0)
- No "JUST LISTED!!!"
- No hashtag soup. ≤2 tags. Skip them entirely if the post stands without.
- No "DM me for details" — give the path.
- 0 Fair Housing red flags

## Variables

- {{hook_feature}}
- {{anchor_number}} (price OR sqft OR year OR lot)
- {{cta_or_link}}
