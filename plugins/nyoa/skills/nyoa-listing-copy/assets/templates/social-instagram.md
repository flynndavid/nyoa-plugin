# Instagram Post Template

**Length:** Caption 80–180 words. Three blocks separated by line breaks. Optimized for the carousel-photo-set format that real estate agents typically post.

## Structure

### Block 1 — The hook (1–2 short lines)
Same hook discipline as the MLS remarks. One concrete, image-forward detail. Buyer self-IDs.

### Block 2 — The story (3–5 short lines)
Walk through the house in order: arrival, kitchen / main living, primary suite, the unique feature, the lot. One detail per line. Use line breaks for breathing room (Instagram rewards short-line cadence).

### Block 3 — The action
- Address (if MLS rules / privacy permit; otherwise neighborhood + price)
- Beds / baths / sqft / price
- Open house time OR "comment OPEN to get the link"
- Up to 5 hashtags. Mix: 2 hyper-local (`#EastNashvilleHomes`, `#615RealEstate`), 2 category (`#Craftsman1924`, `#NashvilleListings`), 1 brand (`#NYOA`).

## Hard rules

- ≤180 words
- ≤5 hashtags
- ≤2 emojis (use sparingly — 🌿 🪟 🔨 work, never 🔥💯)
- 0 Fair Housing red flags
- "Primary bedroom" not "master bedroom"
- No "DM me for details" without a fallback action

## Variables

- {{hook}}
- {{interior_details}} (3–5 lines)
- {{address_or_neighborhood}}
- {{stats}} (beds / baths / sqft / price)
- {{cta}}
- {{hashtags}} (≤5)
- {{tour_url}} (optional — appended to the action block as "Walk it in 3D → [URL]" when `marketing/3d-tour.md` has a Tour URL; skip silently if absent)
