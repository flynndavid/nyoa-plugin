# MLS Remarks Template

**Constraint:** ≤500 characters total. Most MLS systems allow 500–1,000; we target 500 to force precision and stay portable.

## Structure

1. **Hook (sentence 1)** — Lead with one specific, image-forward feature only this house has. Buyer self-IDs in this sentence. No clichés.
2. **Differentiator block (1–2 sentences)** — 2–3 concrete features that back the hook. Named finishes / dimensions / materials / lot. No filler adjectives.
3. **Lifestyle anchor (1 sentence)** — One scene the buyer can step into (Saturday morning, weeknight, work-from-home).
4. **CTA (final sentence)** — Open house time, scheduling link, or call-to-action verb. End on action, not exclamation.

## Hard rules

- ≤500 characters
- 0 clichés ("stunning", "must see", "nestled", "boasts", "luxury living awaits", "don't miss")
- 0 Fair Housing red flags (see `references/voice-presets.md` for the full list)
- 0 unsourced structural claims
- 0 protected-class implications
- "Primary bedroom" not "master bedroom"

## Variables

- {{hook_feature}} — The single most distinctive feature
- {{differentiators}} — 2–3 named features
- {{lifestyle_scene}} — One concrete scene
- {{cta}} — Open house time OR call-to-action
- {{tour_url}} (optional — append " · Walk it now in 3D: [URL]" only if total stays ≤500 chars; otherwise omit, since the URL belongs in MLS's virtual-tour-link field)

## Example output

> Quartz counters and a six-burner Wolf range anchor a kitchen built for someone who cooks. Original 1924 white oak floors, leaded glass over the front door, brick fireplace with the original tile. Three bedrooms up plus a dormered walk-up attic that's already wired — obvious home office or fourth bedroom. Fenced yard, screened back porch, alley-access garage. Open Sunday 1–3.

(489 characters.)
