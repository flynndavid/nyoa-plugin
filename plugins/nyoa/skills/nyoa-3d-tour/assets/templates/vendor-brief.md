# 3D Tour Vendor Brief Template

**Channel:** Email to a freelance scanner.
**Length:** 200–400 words. Scannable on phone.
**Goal:** Standardize the conversation regardless of vendor's experience level. Lock the deliverables before they accept.

## Structure

### Subject line
- "3D Gaussian Splat scan — [address] — [target window]"
- Concrete. No "Quick question" or "Looking for a vendor".

### Body

#### Paragraph 1 — The job
One sentence: what, where, when. Address, sqft, target capture window.

#### Paragraph 2 — Property facts
- Address + neighborhood
- Sqft + floors + bed/bath count
- Indoor vs. indoor + outdoor + lot
- Special considerations (pool, mirrored rooms, glass walls, multi-story atrium)
- Access window + lockbox or agent-on-site
- Pets / occupancy status (should be empty, but flag if not)

#### Paragraph 3 — Required deliverables (this is the lock-in)
Bullet list, every item required:

- Public hosted viewer URL
- Downloadable `.splat` or `.ply` file (agent owns the asset)
- Mobile-tested (iPhone Safari + Chrome on Android)
- No baked-in vendor branding (or removable in paid tier)
- One re-scan included if any room has visible holes
- Turnaround within [N] days of capture
- Privacy: no public posting without agent consent; raw frames deleted after delivery

#### Paragraph 4 — Pricing expectation
"Based on similar [sqft tier] scans in this market, my budget is $[low]–$[high]. If your quote sits inside that range, send a confirmation and we'll book; if not, send your number and I'll come back."

#### Sign-off
First name + agent attribution + license number + brokerage.

## Hard rules

- 0 vague language ("looking for a quote", "let me know what you do")
- 0 protected-class references in the property description
- "Primary bedroom" not "master bedroom"
- Required deliverables must be a literal bullet list — easier for the vendor to accept/decline each line
