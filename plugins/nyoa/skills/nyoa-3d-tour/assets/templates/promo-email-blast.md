# 3D Tour — Buyer Email Blast Template

**Channel:** Email to the agent's buyer list / sphere.
**Length:** Subject ≤55 chars. Body 100–180 words.
**When:** First-drop (the day the tour goes live), or as a re-engagement push to buyers who saved the listing but haven't requested a showing.

## Structure

### Subject line
- Concrete. One feature + the new capability.
- **Good:** "Walk 123 Maple in 3D — before Sunday's open"
- **Good:** "The Sylvan Park craftsman is now a browser tab"
- **Bad:** "🔥 NEW 3D TOUR! Don't miss out!"
- **Bad:** "Virtual tour now available"
- 0 emojis. 0 all-caps.

### Preheader (optional, ≤90 chars)
Second sentence of the email. "Photoreal. No app. Walk every room from wherever you are."

### Body

#### Opening (2 sentences)
What changed today. Why this list is hearing about it (saved this listing / watching this neighborhood / didn't make the open house).

#### The tour block (2–3 sentences)
- What it is (one short sentence — "photoreal 3D walkthrough you open in any browser")
- What buyers can do with it (walk the rooms, look out the windows, see the lot from the porch)
- The link itself (a styled button if HTML, otherwise the bare URL)

#### Property block
- Address + neighborhood
- Price · beds · baths · sqft
- 2–3 features (lifted from the listing's existing copy.md hook — don't reinvent)

#### Action block
- "Tap the tour. If you want to see it in person after, reply or use [scheduling link]."
- Open house time if upcoming.

#### Sign-off
First name. Match agent voice file if available.

## Hard rules

- 0 Fair Housing red flags
- 0 unsourced structural claims
- 0 clichés
- "Primary bedroom" not "master bedroom"
- Subject ≤55 chars
- Body ≤180 words
- The tour link is the primary CTA — don't bury it under three other links
