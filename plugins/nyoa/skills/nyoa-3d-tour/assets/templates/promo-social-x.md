# 3D Tour — X Promo Template

**Length:** ≤280 chars. Single post.
**When:** First-drop post (the day the tour goes live) and/or a price-drop refresh post.

## Structure

One post, three moves:

1. **Line 1 — The hook.** One concrete detail from the listing's existing voice. Match the hook the agent already used in `nyoa-listing-copy` if available.
2. **Line 2 — The shift.** One sentence on what the tour lets the buyer do (walk it before flying in / before the open house / on their lunch break). Concrete, no "experience" or "immerse yourself".
3. **Line 3 — The link.** Bare URL. No "DM me".

## Hard rules

- ≤280 characters total
- 0 emojis
- 0 hashtags (X promo for a single listing doesn't need them — keep it clean)
- 0 "JUST DROPPED!!!" / "stunning" / "must see"
- 0 Fair Housing red flags
- 0 protected-class implications
- Bare URL, not a tracker-laden one

## Variables

- {{listing_hook}} — pull from `copy.md` if available, otherwise the same sentence as MLS hook
- {{tour_action}} — what the buyer can do (walk it now / walk it before flying / walk it before Sunday's open)
- {{tour_url}}
