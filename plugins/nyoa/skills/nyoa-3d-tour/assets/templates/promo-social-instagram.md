# 3D Tour — Instagram Promo Template

**Length:** Caption 80–160 words. Optimized for the carousel-photo format with the tour link as the final swipe / CTA.

## Structure

### Block 1 — The hook (1–2 short lines)
Match the listing's existing voice. One concrete, image-forward detail.

### Block 2 — The "what's new" (3–5 short lines)
What the buyer can now do that they couldn't yesterday. One detail per line.

- "Walk every room. Stand in the kitchen. Look out the upstairs windows."
- "From your couch. From the car line. From three time zones away."
- "Photoreal. Loads on a phone. No app to install."

Don't overhype — concrete actions, not hype phrases.

### Block 3 — The action

- Address (or neighborhood + price if MLS rules / privacy)
- Beds / baths / sqft / price
- Tour link (or "comment WALK to get the link")
- Open house time if upcoming
- Up to 4 hashtags. Mix: 2 hyper-local, 1 category (`#3DTour` or `#GaussianSplat`), 1 brand if used.

## Hard rules

- ≤160 words
- ≤4 hashtags
- ≤2 emojis (sparingly; never 🔥💯)
- 0 Fair Housing red flags
- "Primary bedroom" not "master bedroom"
- 0 invented capabilities ("see every detail" is fine; "see what other agents can't show you" is hype-y)

## Variables

- {{hook}}
- {{whats_new}} (3–5 lines)
- {{address_or_neighborhood}}
- {{stats}} (beds / baths / sqft / price)
- {{tour_url}} or "comment WALK"
- {{open_house_or_link}}
- {{hashtags}}
